Mengapa BFS/DFS Tidak Cukup?

Masalah BFS

BFS optimal dalam jumlah langkah, tapi tidak mempertimbangkan biaya tiap langkah. Jalan tol vs jalan kampung — BFS tidak peduli.

Solusi: Heuristik h(n)

h(n) = estimasi biaya dari node n ke goal.

  • Manhattan: |x₁−x₂| + |y₁−y₂| — grid 4 arah
  • Euclidean: √((x₁−x₂)²+(y₁−y₂)²) — bebas arah
  • Syarat admissible: h(n) ≤ h*(n) — tidak lebay

Tiga Fungsi Evaluasi

UCS: f(n) = g(n)
Greedy: f(n) = h(n)
A*: f(n) = g(n) + h(n)

Semua memakai Priority Queue (heapq) — selalu proses f(n) terkecil.

Praktik 1 — Uniform Cost Search

f(n)=g(n) Optimal
praktik1_ucs.py
import heapq

def ucs(graf, start, goal):
    """
    UCS: proses node dengan g(n) terkecil.
    graf: {node: [(tetangga, biaya), ...]}
    """
    # (biaya_g, jalur)
    pq        = [(0, [start])]
    dikunjungi = {}

    while pq:
        biaya, jalur = heapq.heappop(pq)
        node = jalur[-1]

        if node in dikunjungi:
            continue
        dikunjungi[node] = biaya

        if node == goal:
            return jalur, biaya, len(dikunjungi)

        for nbr, bobot in graf.get(node, []):
            if nbr not in dikunjungi:
                heapq.heappush(pq,
                    (biaya + bobot, jalur + [nbr]))

    return None, float('inf'), 0

# Graf berbobot: kota dengan jarak (km)
graf_kota = {
    'A': [('B',4),('C',2)],
    'B': [('A',4),('D',3),('E',5)],
    'C': [('A',2),('E',4),('F',1)],
    'D': [('B',3),('GOAL',6)],
    'E': [('B',5),('C',4),('GOAL',2)],
    'F': [('C',1),('GOAL',3)],
    'GOAL': []
}

jalur, biaya, n_vis = ucs(graf_kota, 'A', 'GOAL')
print("=== UCS ===")
print(f"Jalur   : {' → '.join(jalur)}")
print(f"Biaya   : {biaya} km")
print(f"Visited : {n_vis} node")
print(f"Optimal : ✅ Ya (biaya minimum)")
