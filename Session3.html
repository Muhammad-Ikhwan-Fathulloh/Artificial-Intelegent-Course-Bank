Ruang Keadaan (State Space)

Problem Solving = Mencari jalur dari state awal ke state tujuan melalui serangkaian aksi.

📌 State (Keadaan)

Representasi situasi saat ini. Contoh: posisi di maze, konfigurasi puzzle 8.

⚡ Aksi (Actions)

Transisi antar state. Di maze: gerak ↑↓←→. Di puzzle: geser tile.

🏁 Tujuan (Goal)

Kondisi terminal. Pencarian berhenti saat goal ditemukan.

Formal: Tuple (S₀, A, T, G)

S₀ — State awal
A(s) — Aksi di state s
T(s,a) — State baru
G — Himpunan tujuan

BFS vs DFS — Perbedaan Utama

Aspek🌊 BFS🔍 DFS
Struktur DataQueue — FIFO (deque)Stack — LIFO (list) / Rekursi
StrategiMelebar level per levelMendalami satu jalur dulu
Complete?✅ Selalu menemukan solusi✅ Ya (jika graph terbatas)
Optimal?✅ Jalur terpendek (cost sama)❌ Tidak selalu
Memori❌ O(bᵈ) — boros lebar✅ O(b·m) — hemat
Kasus TerbaikSolusi dekat dari awalSolusi di jalur pertama (kiri)

BFS menggunakan deque — popleft() mengambil dari depan antrian. Semua node di kedalaman d dikunjungi sebelum d+1.

DFS menggunakan stack/rekursi — pop() mengambil dari belakang. Satu jalur dikejar sampai ujung sebelum backtrack.

Praktik 1 — BFS pada Graf

Queue FIFO Jalur Terpendek
praktik1_bfs.py
from collections import deque

def bfs(graf, start, goal):
    """
    BFS — eksplorasi level per level.
    Mengembalikan (jalur, urutan_kunjungan)
    """
    if start == goal:
        return [start], [start]

    antrian   = deque([[start]])   # antrian JALUR
    dikunjungi = {start}
    urutan     = []

    while antrian:
        jalur  = antrian.popleft()   # FIFO ← depan
        node   = jalur[-1]
        urutan.append(node)

        for nbr in graf.get(node, []):
            if nbr not in dikunjungi:
                dikunjungi.add(nbr)
                jalur_baru = jalur + [nbr]
                if nbr == goal:
                    return jalur_baru, urutan
                antrian.append(jalur_baru)

    return None, urutan   # tidak ditemukan

# ── Graf (adjacency list) ──
# A─B─C─D
# │ │   │
# E─F   G
graf = {
    'A':['B','E'], 'B':['A','C','F'],
    'C':['B','D'], 'D':['C','G'],
    'E':['A','F'], 'F':['B','E'],
    'G':['D']
}

jalur, kunjungan = bfs(graf, 'A', 'G')
print("=== BFS: A → G ===")
print(f"Jalur     : {' → '.join(jalur)}")
print(f"Langkah   : {len(jalur)-1}")
print(f"Dikunjungi: {' → '.join(kunjungan)}")
print(f"Total node: {len(kunjungan)}")

Praktik 2 — DFS Iteratif & Rekursif

Stack LIFO Rekursi
praktik2_dfs.py
# ── DFS ITERATIF (Stack) ──
def dfs_iter(graf, start, goal):
    stack      = [[start]]
    dikunjungi = {start}
    urutan     = []
    while stack:
        jalur = stack.pop()          # LIFO ← belakang
        node  = jalur[-1]
        urutan.append(node)
        if node == goal:
            return jalur, urutan
        for nbr in reversed(graf.get(node,[])):
            if nbr not in dikunjungi:
                dikunjungi.add(nbr)
                stack.append(jalur + [nbr])
    return None, urutan

# ── DFS REKURSIF ──
def dfs_rek(graf, node, goal,
            vis=None, path=None):
    if vis  is None: vis  = set()
    if path is None: path = []
    vis.add(node)
    path = path + [node]
    if node == goal: return path
    for nbr in graf.get(node, []):
        if nbr not in vis:
            hasil = dfs_rek(
                graf, nbr, goal, vis, path)
            if hasil: return hasil
    return None

# ── Bandingkan BFS vs DFS ──
graf = {
    'A':['B','E'],'B':['A','C','F'],
    'C':['B','D'],'D':['C','G'],
    'E':['A','F'],'F':['B','E'],'G':['D']
}
j_bfs, k_bfs = bfs(graf, 'A', 'G')
j_dfs, k_dfs = dfs_iter(graf, 'A', 'G')
j_rek        = dfs_rek(graf, 'A', 'G')

print("═"*52)
print(f"{'Algo':<14} {'Jalur':<20} {'Steps':<7} {'Visited'}")
print("─"*52)
print(f"{'BFS':<14} {'→'.join(j_bfs):<20} {len(j_bfs)-1:<7} {len(k_bfs)}")
print(f"{'DFS iter':<14} {'→'.join(j_dfs):<20} {len(j_dfs)-1:<7} {len(k_dfs)}")
print(f"{'DFS rekursif':<14} {'→'.join(j_rek):<20} {len(j_rek)-1:<7} -")
print("═"*52)

Kompleksitas & Aplikasi Nyata

AlgoWaktuMemoriOptimal?Gunakan saat…
BFSO(V+E)O(V) boros✅ YaPerlu jalur terpendek, solusi dekat
DFSO(V+E)O(h) efisien❌ TidakEksplorasi semua jalur, memori terbatas
DFS RekO(V+E)O(h) call stack❌ TidakKode bersih, kedalaman aman

🌊 BFS dipakai untuk:

  • Google Maps — jalur paling sedikit simpang
  • LinkedIn — degree of connection
  • Game NPC pathfinding (tile-based)
  • Web crawler — level per level

🔍 DFS dipakai untuk:

  • Puzzle solver — Sudoku, N-Queens
  • Topological sort (dependency graph)
  • Deteksi siklus dalam graf
  • Minimax tree (catur, tic-tac-toe)
